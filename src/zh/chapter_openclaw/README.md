# 第12章 OpenClaw：跨平台个人 AI 助理

**阅读层次**：产品与架构案例选读；没有聊天入口需求时可跳过。

本章把 OpenClaw 作为聊天入口与个人助理的案例，研究消息接入之后的身份、会话、工具和权限边界。关注一个入口怎样连接已有能力，并用任务结果检查这些边界。

## 本章迭代

- **上一版的不足**：已有助手主要通过脚本或接口接收输入，尚未说明聊天身份、会话和工具权限如何对应。
- **本章增加**：以产品案例分析消息网关、路由、会话与扩展机制，不要求把已有助手整体迁入该产品。
- **怎样验证**：本书没有统一产品适配器；读者应固定版本与一个渠道，使用受控任务检查身份、来源、权限、失败提示和输出，并注明实际运行与未运行部分。
- **下一步**：有跨会话积累问题时选读[第13章 Hermes](../chapter_hermes/README.md)；无需产品实验时返回[第三部分选择指南](../part3.md)，继续自己的实现。

## 验证与材料边界

本章说明产品与架构的实验方法，不承诺固定时间内接通所有渠道。安装、渠道和扩展接口应在读者选定版本上核验；没有所需运行条件时，可完成设计分析并标记“未运行”。

仓库的离线资料计算 fixture 不调用 OpenClaw，也不能验证该产品的数据处理与权限实现。产品实验应保留相同任务契约，并为新增聊天入口单独加入身份与会话用例。
