# 第23章 项目实战：多模态 Agent

**阅读层次**：综合实践；第21–23章至少选择一个领域，不要求全部完成。

## 本章迭代

- **上一版的不足**：文本来源可引用，不代表模型从截图、语音或视频提取的细节可靠，也不代表界面操作已获得授权。
- **本章增加**：为图像区域、音频时间段和视频帧保留证据定位，分别定义内容理解与外部动作的验收条件。
- **怎样验证**：本章是组件接入与领域实验，真实模型/媒体处理与完整助理需读者实现。用固定图片、音频或短视频核对对象、数值和位置；模糊、静音、冲突证据应报告不确定，GUI 危险动作须在执行前通过权限检查。
- **下一步**：选择一个模态任务通过验收即可结束应用路线。若需自动改进，带着冻结基线和失败轨迹进入[第七部分](../part7.md)，无需先完成所有模态。

> 🎨 *"真实世界的信息不只有文字——图片、语音、视频都是 Agent 需要理解的语言。"*

## 🎓 学习目标

完成本章学习后，你将能够：

- ✅ 理解多模态 Agent 的能力边界和应用场景
- ✅ 用多模态模型实现图像理解与分析，用 DALL-E 实现图像生成
- ✅ 集成语音识别（STT）和语音合成（TTS）
- ✅ 构建一个具备图像和语音能力的多模态个人助手
- ✅ 了解 Computer Use / GUI Agent 的核心架构和安全实践
- ✅ 掌握视频理解和多模态 RAG 的实现方法
