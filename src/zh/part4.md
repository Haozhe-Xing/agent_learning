# 第四部分：协作与集成篇

前面已经有单 Agent 的任务、工具许可和验收基线。本部分处理两类不同的问题：工作是否值得分给多个角色，以及现有工具或其他系统如何通过协议接入。两者都需要明确边界，但不要求一起采用。

| 章节 | 触发条件 | 本章交接产物 | 对照与失败用例 |
|---|---|---|---|
| [16 多 Agent 协作](./chapter_18_multi_agent/README.md) | 存在可独立验证的并行子任务或角色边界 | 交接协议、总预算和聚合验收 | 在相同任务/总预算下与单 Agent 比较；子任务失败不得伪装整体交付 |
| [17 通信协议](./chapter_19_protocol/README.md) | 工具跨进程或跨系统，需统一接口 | 请求/响应契约、错误码和连接生命周期 | 坏请求之后仍可处理好请求；协议接通不授予额外业务权限 |

单 Agent 也可能需要 MCP；使用状态图也不自动需要多个 Agent。若当前没有协作或外部集成需求，可以直接进入[第五部分](./part5.md)，不要为了完成目录而增加角色数量。
