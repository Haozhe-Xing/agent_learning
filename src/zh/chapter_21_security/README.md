# 第19章 安全与可靠性

**阅读层次**：19.1–19.5为核心；19.7–19.8为运行时与评估练习；19.6为固定篇目的研究选读。从第一次工具调用开始回查这些边界。

## 本章迭代

- **上一版的不足**：规则没有命中、引用标签存在、工具退出成功，都不足以证明有权操作或任务完成。普通子进程也不能被称为安全沙箱。
- **本章增加**：区分资料与权限、支撑与覆盖；独立`reference_code/security_boundary/`落实封闭提议、宿主身份/资源许可、内容绑定审批、当前权限复查、本地收据、预算、字段投影与严格同意。
- **怎样验证**：先通过本地11项冻结场景，检查正常效果与越权效果；再运行`examples/integration_tests/test_security_chapter.py`的拒绝、错误、重试和正文片段测试。规则筛查另有`reference-agent/tests/test_security.py`，它不判定通用语义安全。
- **下一步**：把权限矩阵、实际副作用、未知/错误和仍未覆盖的部署要求带入[第20章](../chapter_22_deployment/README.md)。

## 保持一个适中的主线

核心项目仍是[本地资料调研助手](../learning_project.md)，不再新增大型平台。本章先复用已有QA支撑/覆盖，再选做一个仅标准库的授权边界实验。它只读虚构内存资料、写虚构本地公告；不发消息、不运行任意代码，没有登录界面、磁盘持久化或OS沙箱。

```bash
python -m reference_code.security_boundary
python -m unittest examples.integration_tests.test_security_chapter -v
```

从仓库根目录运行，Python 3.11+，无需密钥。目录可单独复制，见`reference_code/security_boundary/README.md`。测试范围与真实模型红队、并发、远程幂等、部署隔离各自列明，不用本地通过代替后者。
