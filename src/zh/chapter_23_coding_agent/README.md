# 第21章 项目实战：AI 编程助手

**阅读层次**：综合实践；第21–23章至少选择一个领域，不要求全部完成。

## 本章迭代

- **上一版的不足**：通用助手的数值任务通过，并不证明它能定位仓库问题、限制修改范围，或给出经过独立测试的补丁。
- **本章增加**：将证据替换为代码索引，将动作限定为可审阅变更，并为理解、生成、测试和撤回建立项目验收卡。
- **怎样验证**：本章为组件设计与组装练习，配套底座不等于完整编程助手。读者选择一个小缺陷，保留修改前失败、修改后通过、未改动的独立测试和 diff；越界文件操作、删除测试及无法回退的失败都不能算完成。
- **下一步**：达到项目验收后可结束应用路线；其他领域可选[第22章数据分析](../chapter_24_data_agent/README.md)或[第23章多模态](../chapter_25_multimodal/README.md)，不要求三项全做。

> 从零构建一个能理解代码、生成代码、写测试和修 Bug 的 AI 编程助手。

---

## 🎓 学习目标

完成本章学习后，你将能够：

- ✅ 综合运用工具调用、记忆系统、RAG、规划推理等核心能力
- ✅ 设计和实现一个完整的 AI 编程助手架构
- ✅ 实现代码索引、语义搜索、代码生成与 Diff 修改
- ✅ 实现自动测试生成和 Bug 修复的全流程
- ✅ 按项目验收卡组装组件，交付可审查的修改与真实测试证据
