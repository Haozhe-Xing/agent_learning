## 本章迭代

- **上一版的不足**：受控的“取资料→提取距离→换算→验收”流程可以完成任务，但复制到另一个助手后，参数、权限和成功判据可能各改一份，逐渐失去一致性。
- **本章增加**：把流程封装成带输入输出契约、版本、依赖工具和验收说明的技能；加载技能复用流程，实际动作仍经过第8章的宿主权限检查。
- **怎样验证**：读者练习：为距离计算技能保存定义、调用轨迹和测试，核对秒/毫秒、缺资料、未知技能及依赖工具未获许可四类行为。仓库没有独立的技能注册器配套入口；第9.5节代码需读者组装运行，不能把前面 Harness 的测试通过当作技能系统已经验证。

## 本章概览

在前面的章节中，我们学会了如何让 Agent 调用工具。但"会用锤子"和"会做木工"是两回事——**工具是单个动作，技能是解决一类问题的完整能力**。本章将介绍 Agent 技能系统的完整体系：什么是技能、如何定义和封装技能、Agent 如何自主学习新技能、以及如何在多 Agent 系统中发现和共享技能。

## 为什么需要单独一章？

你可能会问：工具调用不就够了吗？

![Tool vs Skill 概念对比](../svg/chapter_skill_readme_tool_vs_skill.svg)

一个技能通常包含：多个工具的组合使用、专业领域的提示知识、特定的处理流程、以及从经验中积累的最佳实践。
