# 双语在线书稿出版验收约定

日期：2026-10-22。交付对象：现有中英文 mdBook 在线书稿。依据：用户选择以双语在线书稿为主、原《审读意见》的四项要求及当前技术审校库存。这里定义本项目的交付条件，不代表外部出版认证。

## 读者与范围

面向会写基础 Python、尚未独立交付 Agent 应用的读者。核心任务是理解并实现一个可验证、受预算与权限约束的证据型助手，再按需要选择框架、协作和部署方案。参考代码集中在 `reference_code/`；主线项目保持单 Agent、本地资料和标准库起步，复杂产品、领域工程与训练作为后续分支。

范围包括25章、7部分及前言、环境、主线、附录，中英文各211个 Markdown 文件。文件数量和网站构建通过不能替代全文审读。当前逐章状态、问题和修复证据见 [审校库存](PUBLICATION_INVENTORY.md)；产品事实见 [版本与来源台账](PRODUCT_FACTS.md)。

## 每章交付条件

| 维度 | 可审查的结果 | 验收方式 |
|---|---|---|
| 教学连续性 | 说明要解决的具体失败、前置知识、能力增量、产物和停止条件；核心与选读有明确取舍 | 逐节审读，并检查章级交接与前后输入输出 |
| 示例复现 | 每段代码区分独立程序、依赖前文的片段、接口设计、伪代码或故意错误的反例；提供实际依赖、入口、输入和预期 | 对承诺可运行的路径执行原文或对应唯一实现，保留正常与失败用例 |
| 验收与安全 | 模型提议、宿主许可、执行完成、证据支撑及需求满足分别判定；缺证据、缺权限、超预算不得默认为成功 | 独立预期与反例，验证拒绝发生在实际动作之前；准确说明未实现的边界 |
| 事实与版本 | 产品命令/API/机制固定版本；重要史实、数字及论文结论有可复查的一手依据，推断与教学重建明确标识 | 逐条核验来源、版本、日期和适用条件；未核实项保留待办或移除确定性表述 |
| 双语一致 | 目标、核心解释、代码能力、练习、图表及参考资料实质对应 | 按小节建立对应关系，审核差异；路径和标题数量相同仅作线索 |
| 编辑与图文 | 术语、符号、单位、编号与引用统一；图与正文一致，公式和代码可读 | 正文校对及实际生成页面检查，不能由 SVG XML 解析替代 |

论文与产品材料应先冻结本版选择及核验日期，再补充内容；优先保留支撑教学目标的条目。新论文数量、模型排名和未经同条件比较的性能/价格表不作为本版完整性的指标。

## 在线成品条件

1. 使用正式配置与固定 mdBook/KaTeX 版本构建两语成品；构建工具不修改源配置。
2. 导航、章号、标题深链、内部资源及参考代码入口有效；所有计划发布 SVG 均可解析，明确的历史备份不进入发布目录，正文不得引用已排除资源。
3. 在生成页面检查代表性的正文、长代码、宽表、公式和图文组合，并覆盖桌面与窄屏、明暗主题、键盘导航。记录页面与实际观察；抽样不能写成全书逐页通过。
4. 检查搜索结果和索引体积、跨语入口、资源加载与阅读性能。对可接受的限制写明实际影响。
5. 外部链接、图片/引文来源和使用许可有记录；本地存在与可解析不代表外部内容有效或拥有再发行许可。

## 证据与关闭规则

每项修订保留“问题 → 文件/来源 → 实现 → 验证 → 剩余边界”。测试报告记录日期、环境、实际命令和覆盖范围；替身、真实依赖、真实服务与线上模型分开说明。正文中的输出来自可复现运行或明确标注的示意，不凭期望手写成测试结果。

当前波次优先关闭已定位的运行及安全缺陷，随后按 [审校库存](PUBLICATION_INVENTORY.md) 推进核心路径、产品与双语内容、领域与研究、成品编辑。某个缺陷通过验证，只关闭该缺陷；全章需要上述六个维度均有证据，才可记为全文已审。全书所有必需项完成且成品验收通过，才关闭出版优化目标。
