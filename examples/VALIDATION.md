## 真实依赖与测试替身的边界

ChromaDB 使用真实数据库和固定嵌入向量。测试实际执行了写入、实例重开、用户过滤、删除，并用两个独立进程检查持久化与删除。它没有测试线上 embedding 的语义召回质量。

LangChain 和 LangGraph 是实际安装的库；模型或审查评分为固定替身，因此能复现工具请求、工具消息、权限拒绝、修改次数和最终状态。它们不证明真实模型会正确选择工具或评价内容。

OpenAI SDK 测试通过本地 `httpx.MockTransport` 校验实际请求与响应序列化，没有向服务商发送请求。当前环境未配置 `OPENAI_API_KEY`，真实模型事实性、稳定性与成本没有实测。现有 `--real --model MODEL` 入口可用于补充该验证，不会因环境中存在 Key 就自动切换模式。

Dockerfile 已修正安装路径，但本轮未执行 Docker 构建、外部集群部署或生产负载测试。图像做了静态路径检查和代表性页面显示抽查，不等于全书出版排版审校。

本轮核验重点为核心应用路径、已发现的执行与文档错误；未将所有研究结论、基准数字、训练流程、第三方产品安装步骤和领域项目后端逐项实测。它们应按各章明确的扩展边界另行验证。
